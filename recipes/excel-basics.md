# enter data in Excel

when: excel, spreadsheet, cell, formula, worksheet, column, row

Typing goes into the selected cell. Enter commits it and moves down; Tab
commits and moves right; Escape abandons what was typed and leaves the old
value. Clicking another cell while typing does NOT commit — it inserts that
cell's reference, which is how a stray click turns a number into a formula.

Ctrl+Home returns to A1. The Name Box, left of the formula bar, jumps to any
cell if you type its reference and press Enter.

A formula starts with =. Without it the text is stored literally, which looks
like the formula failed.
