# find a setting in Windows Settings

when: settings, windows settings, control panel, preferences, options, configure

route: dark mode = Personalization > Colors
route: light mode = Personalization > Colors
route: theme = Personalization > Themes
route: wallpaper = Personalization > Background
route: dns = Network & internet > Advanced network settings
route: wifi = Network & internet > Wi-Fi
route: bluetooth = Bluetooth & devices > Devices
route: default apps = Apps > Default apps
route: uninstall = Apps > Installed apps
route: night light = System > Display
route: display = System > Display
route: sound = System > Sound
route: windows update = Windows Update > Check for updates

Settings opens on Home, and most things are one page in from there. The left
sidebar is the reliable way across: System, Bluetooth & devices, Network &
internet, Personalization, Apps, Accounts, Time & language, Gaming,
Accessibility, Privacy & security, Windows Update.

Dark mode is Personalization, then Colors. Wi-Fi and DNS are Network &
internet. Default apps and uninstalling are Apps.

The "Find a setting" search box at the top left is faster than navigating when
the exact name is known, and worse than the sidebar when it is not, because it
matches on words rather than on where things live.
