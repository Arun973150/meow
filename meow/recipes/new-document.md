# start something new in an application

when: new, another, blank, empty, fresh, new tab, new window, new document,
new file, new note, new sheet, new workbook, new slide, new deck, start a new

Almost every Windows application makes a new thing with **Ctrl+N**, and a new
tab with **Ctrl+T**. Those two cover most of what anyone asks for, and they
work whether or not a button for it is visible.

Notepad has tabs: Ctrl+N makes a new tab, and Ctrl+Shift+N makes a whole new
window. There is also an "Add New Tab" button on the tab strip, which does the
same as Ctrl+N — either is fine, and the button is better when it is already in
the control list because clicking a named control can be checked afterwards and
a keystroke cannot.

Word, Excel and PowerPoint: Ctrl+N makes a new blank document, workbook or
presentation. They do not have a new-tab button, so the shortcut is the only
way.

Browsers: Ctrl+T for a tab, Ctrl+N for a window, Ctrl+Shift+N for a private
one.

File Explorer: Ctrl+N opens a second window on the same folder, Ctrl+T a tab.

The application has to be in front first, and the new thing takes a moment to
appear. Check that it did rather than assuming: a new tab changes the tab strip
and a new window changes the window list, so there is always something to look
at.

Do not save, name or close anything unless that was asked for. "Open a new
note" is one action.
